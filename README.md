## 🚀 About The Project

**Raj Computer Center** is a premium, futuristic EdTech platform designed to provide high-quality education in **Programming, Web Development, Cyber Security, and Reverse Engineering**.

This platform is developed with a focus on practical learning, modern technology, and a professional learning management system (LMS) experience. The website features an advanced multi-step admission process, interactive dashboards, and a futuristic UI.

> **"Learning technology by building it."**

---

## ✨ Key Features

- 🖥️ **Futuristic UI/UX**: Dark Tech + Glassmorphism + Animated Grid Backgrounds.
- ⚡ **Loading Screen**: Branded boot sequence with "RC" logo and progress bar.
- 🎓 **Multi-Step Admission Form**: Personal Info → Course → Education → Contact → Account → Payment → Documents.
- 💻 **Laptop & OS Lab**: Detailed section for Windows, Ghost OS, Dell, and HP laptop setups.
- 🛡️ **Cyber Security & Reverse Engineering Lab**: Interactive radar animations and Hex code previews.
- 👨‍💻 **About the Developer**: Premium developer profile with rotating rings, tech stack chips, and dynamic stats.
- 💎 **Premium Pricing Cards**: Animated borders, glow effects, and count-up price animations.
- 📱 **Mobile Responsive**: Fully optimized for mobile devices with bottom sticky navigation.
- 🌗 **Theme Switcher**: Switch between Dark (Tech) and Light modes.
